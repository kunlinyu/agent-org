# agent-org

在 DSH（DeepSeek Harness）之上构建的**单人 AI 开发组织**框架。

一个人像老板一样，指挥一支约 10 个角色的 AI 团队推进复杂项目：所有需要拍板的事汇入收件箱，
裁决后对应 agent 立即恢复运行；反复出现的裁决沉淀为共识规则，使打扰自然变稀；
全部 agent 卡住时系统自然冷却，逐条回复后逐步恢复。

## 三条核心设计

1. **请示 vs 反馈** —— 只影响当前任务的事反馈给上级；会成为以后同类问题依据的事才请示老板。
   于是条目密度 ∝ 新增规范性决策的速度，打扰自然单调递减。
2. **一个上级 + 多个对接人** —— 直系上级能派活、能打断；非上级对接人只能提约束。
3. **代码物理隔离** —— 每个执行者槽位持有独立代码拷贝，push 到中心仓库由研发总监评审合入。
   并发不靠锁，靠隔离。
